//与门 &&    如果1和1那么输出1(真),否者输出0(否)
//或门 ||    如果两值存在1那么输出1(真),否则输出0(否)
//非门 !     求反,输入1则输出0
//            输入0则输出1
//
//同或    如果两值相同那么输出1(真),否者输出0(否)
//异或    如果两值不同那么输出1(真),否则输出0(否)
//
//Tips:
//    所有非0数值都属于真
//
//运算符:
//    变量=表达式:    x=y+z
//
//算术运算符:
//    + :加法,取正值
//    - :减法,取负值
//    * :乘法
//    / :除法
//    % :取余,保留无法被整除的部分
//    = :赋值
//
//关系运算符:     //个人认为可以接if使用
//    > 大于
//    < 小于
//    >=大于等于
//    <=小于等于
//    ==等于
//    !=不等于
//    表达式1  <关系运算符> 表达式2
//
//逻辑运算符:
//    && :Turn to line1
//    || :Turn to line2
//    !  :Turn to line3
//
//位运算符:
//    & :按位与
//    | :按位或
//    ^ :按位异或
//    ~ :按位取反
//    << :左移
//    >> :右移
//
//复合运算符:
//    += :加法赋值
//    -= :减法赋值
//    *= :乘法赋值
//    /= :除法赋值
//    %= :取余赋值
//    <<= :左移赋值
//    >>= :右移赋值
//    例:
//        x*=y    等同于 x=x*y
//
//逗号运算符:
//    , :逗号运算符
//    例:
//        x=1,y=2,z=3    //依次执行，最终结果为z的值,个人感觉可以理解成文本阅读中的逗号
//
//条件运算符:
//    ?: :条件运算符
//
//指针运算符:
//    & :取地址运算符
//    * :解引用运算符
//
//表达式语句:
//    ";"用分号分隔语句
//    {
//    语句块,其内部创建的变量在语句块外部无法访问
//    }
//
//顺序结构:
//    自上到下依次运行
//
//选择结构:
//    成立则执行语句A,不成立则执行语句B
//
//循环结构:
//    如果条件成立,则按顺序继续执行循环体,直到条件不成立,则跳出循环体
//
//if语句:
//    字面意思,如果xxx那么xxx
//    其中if后的括号可以填入运算符
//
